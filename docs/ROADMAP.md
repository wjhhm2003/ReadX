# 开发路线

## P0 / P1：阅读基础（当前）
- [x] Android 构建环境和 Gradle Wrapper
- [x] Compose + Material 3 Expressive 界面
- [x] SAF 导入、私有副本、去重、失败回滚
- [x] Room 书库与章节持久化
- [x] TXT 编码识别和规则分章
- [x] EPUB OPF / nav / NCX 与基础滚动阅读
- [x] AndroidX PDF 高级路径 + PdfRenderer 回退
- [x] 目录、基础进度、正文主题与排版
- [x] 元数据基础编辑、标签、文本搜索
- [ ] 对真实书籍集做兼容性与内存基线测量

## P2：阅读体验与稳定定位
- 引入/评估 Readium EPUB 引擎，保持书库数据不依赖具体引擎。
- 稳定文字位置：资源 href + 文字偏移/前后文；换字体与布局后重定位。
- TXT 手动编码切换、目录规则预览、目录修改与重新生成。
- [x] EPUB 位图封面、PDF 首页缩略图。
- [x] TXT/EPUB 屏幕分页与滚动切换、章末连续翻页。
- [ ] EPUB 完整目录锚点层级、首行缩进、对齐、自定义字体。
- 引用/脚注浮层、跳转返回栈；外链必须由用户确认后才交给外部应用。
- PDF 目录、缩略图、裁边、阅读模式、页码标签与精确视口恢复。
- 完整中英文本地化与无障碍字体缩放。

## P3：批注与搜索
- [x] TXT/EPUB 基础章节/相对位置书签（后续升级精确文字锚点）。
- [ ] EPUB/TXT 高亮、划线、摘录、笔记，必须建立在稳定文字锚点上。
- PDF 页码 + 归一化四边形定位；缩放/旋转/裁边后标注不漂移。
- 批注统一管理；Markdown 和 JSON 导出及恢复。
- Room FTS/中文索引评估；可取消、渐进的书内和全书库搜索。

## P4：词典、翻译与知识管理
- 离线词典导入和查词面板；不预装大型词库。
- 可替换翻译提供器：可选离线模型/在线接口；仅发送主动选中内容。
- 元数据刮削候选确认、字段来源、手动值保护。
- 独立笔记标签、批量操作、书库+批注一致性备份恢复。

## P5：PDF 深化与性能
- 大文件/长文档/双栏论文/扫描件/字体/复杂图表/密码 PDF 测试集。
- OCR 按需任务；无目录 PDF 的标题推断；失败可取消与恢复。
- 局部重渲染、缓存上限、邻页预加载、背景节能、内存压力恢复。
- 包体与 R8 验证、崩溃与损坏文件恢复、正式签名发布。

不把 beta 查看器集成成功当作「优秀的 PDF 支持」已经验收。当前仍是阅读基础开发预览。
