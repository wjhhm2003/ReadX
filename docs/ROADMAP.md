## P2：阅读体验与稳定定位
- 引入/评估 Readium EPUB 引擎，保持书库数据不依赖具体引擎。
- [x] 基础批注文字位置：章节 href + UTF-16 偏移/原文/前后文，换排版后重定位。
- [ ] 普通阅读进度全面升级到文字锚点与 Readium CFI 兼容。
- TXT 手动编码切换、目录规则预览、目录修改与重新生成。
- [x] EPUB 位图封面、PDF 首页缩略图。
- [x] TXT/EPUB 屏幕分页与滚动切换、章末连续翻页。
- [x] 首屏优先、复用当前章实测页数、邻章优先渐进统计、完整/部分布局缓存与取消；会话内重排文字锚定。
- [ ] TXT 原生渲染/分页的性能对照、复杂 EPUB 与低端设备的长期分页/内存基线；不以独立文本引擎的估算代替 Chromium 实测总数。
- [ ] EPUB 完整目录锚点层级、首行缩进、对齐、自定义字体。
- [x] TXT/EPUB 平移过渡、三分屏点击、全书实测页码滑条与章节预览、全展开弹层、设置重置和纯黑主题。
- [x] 完整应用主题色 / RGB 自定义 / 可关闭动态取色，阅读纸张独立。
- [x] 默认沉浸式全尺寸阅读、覆盖式下栏、选区旁批注菜单、标记颜色与阅读页取消；重复记录 upsert、显示透明度不叠加。
- [x] PDF 横向单页模式。
- [x] 章节内/跨章节本地链接停留与会话返回栈（章节/相对位置，最多 32 层）。
- [ ] 引用/脚注浮层、非 spine 注释、精确文字来源锚点与持久化返回链；外链必须由用户确认后才交给外部应用。
- PDF 目录、缩略图、裁边、阅读模式、页码标签与精确视口恢复。
- 完整中英文本地化与无障碍字体缩放。

## P3：批注与搜索
- [x] TXT/EPUB 基础章节/相对位置书签（后续升级精确文字锚点）。
- [x] EPUB/TXT 荧光笔、下划线、文字笔记与按书籍分组；DOM 文字偏移 + 引用上下文定位。
- [ ] 通用 EPUB CFI、复杂版式锚点兼容、摘录与批注导出。
- [x] PDF 页码 + 归一化矩形的荧光笔/下划线/笔记与重开恢复。
- [ ] PDF 四边形、文档页旋转/裁边后的定位兼容与导出。
- 批注统一管理；Markdown 和 JSON 导出及恢复。
- Room FTS/中文索引评估；可取消、渐进的书内和全书库搜索。

## P4：词典、翻译与知识管理
- 离线词典导入和查词面板；不预装大型词库。
- 可替换翻译提供器：可选离线模型/在线接口；仅发送主动选中内容。
- 元数据刮削候选确认、字段来源、手动值保护。
- 独立笔记标签、批量操作、书库+批注一致性备份恢复。

## P5：PDF 深化与性能
- 大文件/长文档/双栏论文/扫描件/字体/复杂图表/密码 PDF 测试集。
- [x] 离线 PDF 逐页文字/OCR 转独立 EPUB，全局按需开关、SAF 模型导入、后台进度/取消/续算、原页回看及 EPUB 导出。
- [ ] 竖排/手写/复杂扫描版面、插图/公式/表格的可靠区域级检测、复杂脚注、OCR 校对与低端设备长期压力。
- 无目录 PDF 的更完整标题推断；更精确的错误定位和恢复。
- 局部重渲染、缓存上限、邻页预加载、背景节能、内存压力恢复。
- 包体与 R8 验证、崩溃与损坏文件恢复、正式签名发布。
